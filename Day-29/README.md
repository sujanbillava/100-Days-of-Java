# Day 29 - Strings in Java

Today I learned the basics of **Strings in Java**.

## Topics Learned

* What is a String?
* Difference between `String` and `char`
* Creating a String
* `length()`
* `charAt()`
* `equals()`
* `equalsIgnoreCase()`
* `substring()`
* `contains()`
* `toUpperCase()`
* `toLowerCase()`
* String object
* Difference between `==` and `equals()`

## Practice Program

I created a Java program that:

1. Takes a String from the user.
2. Finds the String length.
3. Prints the first character.
4. Prints the last character.
5. Converts the String to uppercase.
6. Checks whether the String contains `"Java"`.
7. Compares the String using `equalsIgnoreCase()`.

## Key Learning

`equals()` compares the content of Strings, while `==` compares object references.
