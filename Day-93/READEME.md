# Day 93 – Singly Linked List

## 📌 What is a Singly Linked List?

A **Singly Linked List** is a linear data structure made up of nodes. Each node stores data and a reference to the next node. The nodes are connected using references, allowing us to traverse the list in the forward direction.

The last node points to `null`, indicating the end of the list.

## 🧩 Structure of a Node

Each node contains:
- **Data:** Stores the value.
- **Next:** Stores the reference to the next node.

## 🔗 Example

```text
Head
 ↓
10 → 20 → 30 → 40 → 50 → null
```
