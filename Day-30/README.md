# Day 30 - StringBuilder in Java

 **StringBuilder** in Java and how it can be used to modify text efficiently.

## Topics Learned

* What is `StringBuilder`?
* Creating a `StringBuilder`
* `append()`
* `insert()`
* `setCharAt()`
* `reverse()`
* `toString()`
* `length()`

## Important Methods

| Method        | Purpose                             |
| ------------- | ----------------------------------- |
| `append()`    | Adds content at the end             |
| `insert()`    | Inserts content at a specific index |
| `setCharAt()` | Changes a character at an index     |
| `reverse()`   | Reverses the StringBuilder          |
| `toString()`  | Converts StringBuilder into String  |
| `length()`    | Returns the number of characters    |
