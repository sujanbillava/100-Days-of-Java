#  100 Days of Java 

I started this challenge to strengthen my programming fundamentals, improve my problem-solving skills, understand Data Structures and Algorithms (DSA), and prepare for technical interviews and software development opportunities.

Throughout these 100 days, I practiced Java concepts step by step, solved programming problems, revised previous topics, debugged errors, and applied my learning by building a mini-project.

This repository documents my learning progress, daily coding practice, and growth as a programmer..


### Phase 1: Java Fundamentals — Days 1–20

- Basic Java program structure and `main()` method.
- Variables, data types, and user input using `Scanner`.
- Conditional statements: `if`, `else`, and `switch`.
- Loops: `for`, `while`, and nested loops.
- Number-based programming problems.
- Digit extraction, reversing numbers, and palindrome checking.
- Methods, parameters, and return values.
- Method overloading.
- Arrays and basic array operations.
- Linear search and introductory problem-solving.

**Practice examples:** Calculator, number guessing, palindrome, sum of digits, reverse number, digit count, highest number, and even-or-odd checking.

##  Student Management System

For my final day, I developed a menu-driven Student Management System using Core Java.

**Features implemented:**
- Display all students.
- Search for a student by ID.
- Add a new student.
- Update student marks.
- Delete a student.
- Calculate a student's grade.
- Exit through a menu-driven interface.

**Technologies and concepts used:**
- Java
- Classes and objects
- Constructors
- `ArrayList`
- `Scanner`
- Methods
- Loops and conditional statements
- `switch` statement
- Searching and updating records

**Current limitation:** Student records are stored in memory, so changes are not retained after the program exits. Permanent storage could be added using file handling or a database.
