# Day 70 – Multiple Threads in Java

## 📌 Topic

**Multiple Threads**

## 📖 What are Multiple Threads?

Multiple threads means having **two or more threads running within a single Java program**. Each thread can perform a different task concurrently.

Example:

* Download thread → downloads a file
* Upload thread → uploads a file
* Processing thread → processes data

## 🧵 Thread

A **thread** is a lightweight unit of execution that performs a specific task inside a program.

## 🔄 Multiple Threads

Multiple threads allow a program to perform **multiple tasks concurrently**.

The execution order of threads is **not guaranteed** because the JVM/operating system scheduler decides when each thread gets CPU time.
