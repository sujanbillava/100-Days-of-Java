## Important Concept
ArrayDeque allows adding and removing elements from both ends.

- addFirst() → adds at front
- addLast() → adds at rear
- peekFirst() → sees front without removing
- peekLast() → sees rear without removing
- removeFirst() → removes front
- removeLast() → removes rear

## Duplicate Values
ArrayDeque allows duplicate values.

Example:
[10, 20, 10, 30]

Unlike Set collections, ArrayDeque does not automatically remove duplicates.

## Key Learning
ArrayDeque allows elements to be added, removed, and viewed from both the front and rear.
